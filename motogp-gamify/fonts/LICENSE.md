# Fonts

**Barlow Condensed** (`BarlowCondensed-*.woff2`) is free under the SIL Open Font License 1.1 (https://openfontlicense.org), from Google Fonts.

Livewire's own typefaces (GT Flexa by Grilli Type, Aktiv Grotesk by Dalton Maag) are commercial and are not included. Swap them in via `js/brand.js` if Livewire supplies licensed web fonts. The closest free match for GT Flexa is Archivo, which has a variable width axis.
