# Livewire brand files

Waiting on the Livewire logo as a file. When it arrives, add these here:

- `logo.webp`: the logo as white artwork on a transparent background. It's tinted for the trackside boards, the gantry and the car's decals.
- `logo-ui.webp`: the full-colour logo for the dark menus and HUD.

Then set `logo` and `logoUi` in `js/brand.js` and run `node tools/build.mjs f1-livewire`. Until then, the game uses the text wordmark "LIVEWIRE".
