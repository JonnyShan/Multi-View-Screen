# Fonts

Both fonts are free under the SIL Open Font License 1.1 (https://openfontlicense.org), from Google Fonts:

- **Antonio** (`Antonio-var.woff2`, variable weight 100–700): the racing and UI type. Wild Turkey's promotions site uses it for headings.
- **Zilla Slab** (`ZillaSlab-600/700.woff2`): headings and the text wordmark fallback.

Wild Turkey's own typefaces (WT Heading, WT Caption, Flama) are commercial and are not included. Swap them in via `js/brand.js` if the client supplies licensed web fonts.
